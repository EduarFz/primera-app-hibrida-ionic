# 🛍️ Mi Tienda Virtual - Ionic

Aplicación híbrida desarrollada con Ionic y Angular.

------------------------------------------------------------------------

## ✅ Requisitos

-   Node.js (versión LTS)
-   Ionic CLI (`npm install -g @ionic/cli`)
-   Android Studio
-   SDK de Android configurado

------------------------------------------------------------------------

## 🚀 Instalación

1.  Descargar o clonar el repositorio.

2.  Ubicarse dentro de la carpeta del proyecto:

    cd nombre de la carpeta

3.  Instalar dependencias:

    npm install

------------------------------------------------------------------------

## 🌐 Ejecutar en Navegador

ionic serve

------------------------------------------------------------------------

## 📱 Ejecutar en Android

1.  Construir la app:

    ionic build

2.  Sincronizar con Capacitor:

    ionic cap sync

3.  Abrir en Android Studio:

    ionic cap open android

4.  Presionar ▶ Run en Android Studio.

------------------------------------------------------------------------

## 🔁 Nota

Cada vez que hagas cambios en el código, debes ejecutar:

ionic build ionic cap sync
